# 用量面板指标精简方案

## 目标

缓存复用倍数（原名称“杠杆”）与缓存命中率由同一组输入数据推导，重复展示增加理解成本。用量面板统一保留缓存命中率，移除倍数指标。

## 影响范围与实现

- 修改 `packages/dsh-plugin/src/client/components.tsx`，从输入框上方用量条及共用详情面板移除倍数、悬浮说明和不再使用的格式化函数导入。
- 保留底层 `cacheLeverage` 字段及计算公式，保持现有服务、统计工具和接口兼容。
- 同步插件 README 与现有界面渲染断言。

## 验证

运行客户端测试、插件构建与仓库要求的插件验证脚本，确认用量条和详情均保留命中率且不再渲染倍数。

实际验证：53 项客户端测试、插件构建、插件类型检查，以及 HTTP 冒烟（55 项）、Cordis 装载（10 项）、Node 模块解析（9 项）、浏览器产物（25 项）均通过。本机已安装插件的 `client.js` 已备份并替换，保留其发布包模块标识。未重启正在运行的 DSH，当前页面效果尚未现场验证。

环境诊断：`diagnose-boot.ts web` 在 Bun 下加载既有 `dsh-code-runtime-worker-thread` 时报告 `node:module` 缺少 `stripTypeScriptTypes` 导出；脚本虽然退出码为 0，此项不视为通过，与本次组件修改无关。
