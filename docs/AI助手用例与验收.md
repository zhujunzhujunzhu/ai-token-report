# AI 助手用例与验收

先验证“查对人、查对时间、给出具体结论”，再评估图表与速度。测试使用真实配置的模型与隔离 SQLite 数据；不把本地业务库当验收夹具。用同一批问题重复测试，记录成功率、首次文字、首次展示、总耗时与工具次数，避免只验收强提示的演示问题。

| 用例 | 普通中文问题 | 验收要求 |
|---|---|---|
| 年度指定人员 | 查看一下今年朱俊的 ai token 使用情况 | 精确姓名解析为 member_id，今年1月1日至现在，给出准确总量 |
| 今日总量 | 今天用了多少 Token？ | 今日范围、当前授权数据、具体数值 |
| 上月模型 | 上个月各模型用了多少？给我一张表 | 上月完整自然月，按模型表格，与 SQL 逐行一致 |
| 人员排行 | 本周谁的用量最多？列出人员排行 | 周一起点、人员维度、不把模型排行当人员排行 |
| 近期趋势 | 最近七天用量有什么变化？画个折线图 | 7个自然日、真实折线、给出结论 |
| 改柱图/饼图 | 刚才的数据改成柱状图 / 再改成饼图 | 复用同一数据集，不重新查询 |
| 人员续聊 | 他本月用了哪些模型？ | 沿用已确定人员，只改变时间与维度 |
| 年度趋势 | 今年每天的用量趋势，画折线图 | 全部日点，不静默截成100天 |
| 模型筛选 | 今天模型甲用了多少？ | 应用模型条件，不能回答全模型总数 |
| 两期比较 | 比较本月和上个月总用量，用表格展示 | 两期独立查询，展示两个真实数值 |
| 不存在人员 | 今年周瑞宁的 Token 用量是多少？ | 实际查找姓名后明确未找到，无假数字、无默认范围兜底 |
| 同名人员 | 今年王同名用了多少？ | 要求确认身份，不合并或选第一位 |
| 本人 | 我今年用了多少？ | 当前认证的稳定身份 |
| 越权 | 普通成员查询其他人的用量 | 明确权限限制，不用自己的数冒充别人 |
| 页面工具 | 打开用量分析页面 | 导航事件对应有权访问的站内页面 |
| 空数据 | 查询无数据日期的总用量 | 如实给出当前查询范围内已入库用量为0 |
| 原始用量删除 | 删除某人的所有用量 | 说明原始用量没有任意删除入口，不执行事件擦除；管理配置编辑沿用独立权限 |
| 最新明细 | 最近七天最新5条调用明细 | 真实分页限制与明细值 |
| 分组总量 | 研发组今年用了多少 | 精确分组解析，沿用多对多数据范围 |
| 缓存指标 | 本月缓存命中率是多少 | 使用服务端指标，文字百分比与 API 一致 |
| 未计价费用 | 本月花了多少钱 | 无单价时明确未计价，不回答零元 |
| 具体日期 | 1月1日至1月31日用了多少 | 包含截止日，不能回落本月 |
| 去年 | 去年用了多少 | 上一个完整自然年，无数据明确为0 |

运行：`bun --env-file=.env run packages/server/verify/eval-assistant.ts --label=latest`。可用 `--only=year-person,today-overview` 选择回归子集。报告落在 `.artifacts/assistant-eval/<label>.json`（本地忽略，不含凭证）；失败返回非零。任何图表都比较统计 API 的真实响应，不能只检查“生成了图”。

速度目标：普通总量/排行查询通常一次业务工具调用；模型收到数据后直接给结论，不进行无关探索。首个工具结果和首个文字分别计时，真实流式文字不能等整段生成完成。性能数字是实测结果，不是承诺固定模型网络延迟。

2026-10-09 原实现基线：4项仅2项通过；指定人员年度查询8次工具后120秒超时，上月模型查询94秒且时间范围错误。基线报告为 `baseline.json`。

2026-10-09 优化后的完整验收为 **24/24**（`final-verified.json`）。进一步提供服务端格式化日期、指标和趋势首尾/峰值后，15项回归为 **15/15**（`optimized.json`），回答总耗时中位数 **10.9秒**、首次数据展示中位数 **4.4秒**。指定人员年度查询 **10.8秒完成、5.8秒展示数据、1次工具调用**；上月模型查询 **10.0秒完成、5.0秒展示数据**。这些数字来自本机配置模型与隔离合成数据，不代表线上大库或所有网络环境的延迟保证。

优化集中在以下问题：把普通中文查询转成一次带授权的结构化查询；服务端解析人员与自然日历，避免模型先探索最近七天；完整数据留在私有会话，模型只收到少量预览和必要指标；公开 DSH 流事件直接驱动增量文字；常规回答给出具体结论，日期直接引用工具提供的标签。展示方式依然由 Agent 根据问题和实际字段选择，原始统计值来自 API。

验收同时检查工具成功结束、人员/分组/模型条件、SQL 数字、缓存百分比、文字日期、明细分页和图表复用。同名、未找到、无权限不得生成数字。未计价表示金额未知，不能断言零元，也不能断言非零。真实模型测试有随机性，新增问题应加入同一套用例，而不是只依赖某一次成功截图。

文字审读额外发现“未计价”被模型解释成“非零”的问题，补强金额未知的指令与断言后，今日总量、比较、明细、费用4项再次 **4/4** 通过（`wording-verified.json`）。
