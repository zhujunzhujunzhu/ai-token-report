## 执行的操作

1. **安装 Bun 1.4.2**
   - 官方脚本 `curl bun.sh/install` 在本机**不可用**：它走 GitHub releases 下载，
     而 `objects.githubusercontent.com` 从本服务器**不可达**（20s 超时）。
   - 改用 npm registry 分发：`https://registry.npmjs.org/@oven/bun-linux-x64/-/bun-linux-x64-1.4.2.tgz`
   - 安装到 `/usr/local/bun`，软链 `/usr/local/bin/bun`
   - 二进制最高要求 `GLIBC_2.17`，与本机 glibc 2.17 相符，实测可正常运行

2. **安装 PM2 7.0.4** 到 node20 全局目录（`npm install -g pm2@7.0.4`）

3. **切换 systemd `pm2-root.service`** 的 PATH 与 ExecStart 到 Node 20

4. **切换 `/usr/local/bin/pm2`** 软链到 node20 的 pm2

5. **修正 `/root/.bashrc` PATH**：node16 → node20（原文件备份为 `.bashrc.bak-*`）

6. **补齐 node20 下缺失的 `npm`/`npx`/`corepack` 软链**
   - 原先 `/usr/local/bin/npm` 指向 `node20/bin/npm`，但**该文件不存在**
   - 之前靠 PATH 中更靠前的 node16 目录兜底，改 PATH 后才暴露

7. **`pm2 save`** 持久化进程列表

```bash

```
