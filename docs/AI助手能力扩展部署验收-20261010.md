# AI 助手能力扩展部署验收（2026-10-10）

方案和用例见 [AI助手能力扩展方案与用例](AI助手能力扩展方案与用例.md)。本次交付部门看板的助手能力；沿用既有 DSH Agent 与数据库权限，没有数据库 schema 迁移。

## 实现范围

- 人员基础资料与分组归属、分组名称、供应商/模型归一化、项目归一化、模型单价可按当前权限新建或编辑。角色、账号密码和 appKey 的写操作继续使用对应管理页。
- 删除规则、删除单价和停用人员/分组必须先生成目标明确的确认卡。点击确认才执行；取消、过期、目标变更、权限变化、重复确认均不能写入。
- 公开网络搜索和网页读取，提供可点击来源，阻止服务端内网、保留地址、凭据 URL 和私网重定向。
- 生成并下载真实 docx/xlsx/html/md/csv/txt 文件。统计文件使用授权数据快照，标注窗口、时间、导出行数和分页范围；一般说明和清单可使用文本内容。
- HTML 默认私有；主动分享后生成 1 小时至 30 天的链接，默认 24 小时，支持复制、撤销。到期、会话删除或归属人的数据范围变化后停止访问。
- 站内导航同步时间、来源、模型、人员和分组筛选；管理页同步搜索。续聊文件状态和加载中的管理刷新保持一致，不因缓存名册静默扩大筛选。
